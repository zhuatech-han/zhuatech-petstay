# PetStay 操作手册

## 宠物主

注册并登录，填写本人联系渠道，在“我的宠物”登记猫犬、体重和私有照护说明。“我的需求”选择一只宠物、地区、寄养或上门、日期和准确交接地点；草稿检查后发布。打开需求查看按规则匹配的候选及真实报价，核对固定金额与安排后选定一份报价。准确地址在成单后仅对指定参与方和授权运营人员可见。

“照护订单”查看每日任务、追加修订、交接说明和私有照片。服务方提交完成后核对并确认；需要补充时提交争议说明，服务方回应后再次确认。完成后可评价，运营审核后才公开。未开始订单取消前必须退清已登记线下款项。改宠物资料不会改已确认订单快照。

## 照护者

会员在“提供照护”提交公开名称、地区、服务类型、物种、体重限制、容量及价格，另填私有寄养地址；等待运营审核。发布可用日期段后查看符合规则的需求、提出报价，报价48小时有效。选择后在本人订单核对双方资料；约定日期内开始照护，逐项完成当日任务，追加说明或照片。图片需真实PNG/JPEG、≤2MiB，系统实际解码并去除元数据，不接受文件扩展名伪装。

只登记已核实的线下收款，不通过平台扣款。退款选择原收款，保留原单和不可变流水；完成后只可退回原收款，不能追加收款。交接前完成截至当日任务；提前结束会取消未来任务并保留历史，固定报价不自动重算。新寄养订单开始时登记实际入住状态与随行物品；完成当天任务后填写实际接回人、现场状态与物品交还，再提交主人确认。未登记接回持续占位，超期任务由后台每30秒补充。历史订单标明旧流程，不补造入住记录。

## 运营和管理员

运营审核照护方公开资料、批准或拒绝评价、查看范围内订单及报表／审计，不冒充主人验收或服务方照护。资料审核不等于身份、兽医、保险或资质认证。管理员维护账号、团队、角色、系统设置和字典；公开会员角色受保护。禁用账号、团队或变更权限后现有请求实时复核；不能移除最后一个完整管理员。

## 使用提醒

日历必须连续覆盖需求，容量按服务类型及窗口分别核验。页面出现版本冲突，刷新核对后再决定；不要重复点击或自动重放写入。证据、联系资料与备份需专人管理，不上传公开仓库。测试数据以TEST标注，不代表真实营业门店或评价。

## 门店负责人、店长和员工

“门店与排期”选择本人门店，负责人可启用新订单员工模式，邀请已注册账号。员工在自己的门店页接受邀请，店長可以邀请照护员工，只有负责人可邀请店长。邀请不直接提升平台角色。

先添加对应日期与窗口的可工作班次，再逐日在日程中分派订单。员工模式订单全部任务日都有有效安排后，负责人或店长才能开始照护；只有对应责任人能记录当天任务和上传照片。已有完成任务不能改责任人。移交未完成责任后才能撤销员工关系或删除占用班次。员工上门每时段最多一单，寄养每天最多五只且不与上门混排；跨店与本人旧模式订单同时核验。

“消息与提醒”可查看未读消息、邮件队列状态，配置是否接收每日提醒及平台时区提醒整点（默认上海）。邮件服务未配置时只有站内消息；部署方启用SMTP后，输入本人邮箱，使用邮件验证码验证，再主动启用邮件。失败会显示等待重试或最终失败，站内记录继续保留。SMTP接受不代表进入收件箱，账号或员工权限撤销后旧队列停止发送。验证码不是找回密码凭据。
