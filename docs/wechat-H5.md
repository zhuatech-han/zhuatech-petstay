# PetStay 手机H5与微信接入

知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 微信 zhuatech / zhuatech2。

## 当前交付

同一Vue网页提供手机布局、菜单、宠物档案、发布需求、选择报价、照护记录和双方交接；中英文可切换。使用普通账号登录。没有依赖微信JS-SDK，因此可作为手机网页部署；当前验收为桌面Edge及390×844手机尺寸浏览器，真实微信iOS／Android设备和公网HTTPS尚未验收。

## 账号准备后

先依部署说明准备独立HTTPS域名与服务器，验收移动端Cookie、登录、上传、详情刷新及安全响应头。确认账号实际功能权限后，可配置公众号菜单／文章链接到H5地址；链接方式不等于实现微信登录或原生小程序。账号配置和域名要求以微信官方后台及文档为准，不在公开仓库放AppSecret。

微信OAuth、支付、JS-SDK拍照、订阅消息、原生小程序均未实现，后续需真实账号、服务端密钥安全管理、域名配置与专门集成验收。不要把预留计划描述为已完成集成。参考入口：[微信公众平台开发文档](https://developers.weixin.qq.com/doc/offiaccount/Getting_Started/Overview.html)。
